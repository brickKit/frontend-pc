# frontend-pc

组件 `frontend/pc`（PC 办公入口）的仓库：Vue 3、TypeScript、Ant Design Vue 与 vxe-table 的单页应用，pnpm 工作区。旧版本（1.x）在分支 `legacy/v1`；本主分支按终局设计从零开始（D59），版本从 `3.0.0` 起（A110）。

- 设计：[docs/design.md](docs/design.md)
- 代码在哪、怎样构建与测试：[AGENTS.md](AGENTS.md)
- 跨组件的规则：装配项目 [be-assembly-standard](https://github.com/brickKit/be-assembly-standard) 的协议 20、前端技术栈与边界卡 `docs/zh/07-components/frontend.md`
